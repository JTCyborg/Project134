# AMI486 POST flow — 2026-11-16

## Confirmed control flow

- F000:D604: reads KBC status port 64h and tests bit 2.
- If bit 2 is clear: JMP F000:88CE.
- If bit 2 is set: JMP F000:8A04.
- F000:88CE: installs SS=CS and checks CR0.PE using SMSW.
- PE=1: branch to F000:891E.
- F000:891E: JMP F000:D60F.
- F000:D60F: JMP F000:D6DE.

## Alternate paths

- F000:8904 and F000:8906 dispatch to F000:EE94.
- F000:8919 dispatches to F000:EE9D.
- The 88CE-89EC area contains overlapping instruction streams and
  stack-based control flow. Linear disassembly is insufficient.

## ALi1429 register access helpers

- F000:8DCF: index write to port 22h, data read from port 23h.
- F000:8DDC: index write to port 22h, data write to port 23h.
- F000:8DED: another index/data read sequence.

These are consistent with the PCem ALi1429 index/data port model.
